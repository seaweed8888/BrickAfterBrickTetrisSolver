# BrickAfterBrickTetrisSolver
tetris bot for a web game(https://www.nigelsylvester.com/) using a dxcam based screen reader and based on the Pierre Dellacherie algorithm and also tried using the stack rabbit implementation

Head to the website and run main.py. Make sure than You are on chrome, and the zoom is at 100%.

It could consistently beat the high score and survived until timeout. Issue with sever side session time limit didn't allow me to log my score so I did not end up winning the Jordans :(.
